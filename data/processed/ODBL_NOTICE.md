# Open Database License (ODbL) 1.0 — Attribution & Compliance Notice

## 1. Required Attribution
This data pack contains public transit station and stop coordinates, names, and tags extracted from **OpenStreetMap (OSM)** under the **Open Database License (ODbL) 1.0**.

**Mandatory Attribution Notice to Users:**
> "Contains information from OpenStreetMap and OpenStreetMap Foundation, which is made available under the Open Database License (ODbL). © OpenStreetMap contributors."

**Mobile App Display Requirement:**
In the WakeMe Android Application:
1. The **Settings / About** screen must display:
   *"Stop and station data © OpenStreetMap contributors. Available under the ODbL license (openstreetmap.org/copyright)."*
2. If an interactive map view (e.g. Mapbox, MapLibre, OSMdroid, or Google Maps with OSM overlays) displays stop markers, an attribution link or text overlay must be visible in the corner of the map or easily accessible.

---

## 2. Share-Alike (Public Derivative Databases)
Under Section 4.4 of the ODbL:
- If you publicly use or distribute an **Adapted Database** (e.g., if you enrich this stop database with proprietary user survey data or custom corrections and distribute the database itself), you must make that adapted database available under the ODbL.
- However, if the database is merely used internally by your mobile application to trigger geofence alarms (Produced Work), you do not need to open-source your mobile app's private algorithms or source code, provided the data attribution is prominently displayed.

---

## 3. Commercial Use
ODbL allows commercial use, provided that attribution is preserved and any publicly redistributed derivative databases are offered under the ODbL.
